Mastering Switch Layers in Moho

Imagine you have a magic deck of picture cards stored in a single folder. One card shows a Smile 😊, one shows an "O" mouth 😮, another shows a Surprise 😲, and another shows a Talking Mouth 🗣️. A Switch Layer lets you pick which card is visible with 1 click! It is the secret trick professional studios use for mouth talking (lip sync), eye blinks, and hand shapes!

📖 Complete How-To Guide (All Steps Unlocked)

Read through each step below to learn how Moho Switch Layers work, then try it in the simulator below!

All 5 Steps Active
1 Open New Layer Menu Moho Layers Window

Click the "+" New Layer Button

Look at the Layers Panel on the right side of Moho. At the top left of the panel, click the button marked with a glowing + (New Layer) icon.

Pro Tip: You can also go to the top screen menu and click Layer > New Layer!
2 Select Layer Type Dropdown List

Choose "Switch" Folder

A menu will pop up showing options like Vector, Bone, and Group. Click on Switch (it has a double-arrow icon 🔁). This creates a special magic folder!

What it does: A Switch folder automatically hides all drawings inside except for the ONE drawing you select!
3 Name Folder Organization

Give Your Switch Folder a Name

Type a clear name like "Mouth Shapes", "Eye Blinks", or "Hand Gestures". Good names keep your Moho project tidy when you build bigger cartoon characters!

Moho Naming Tip: Always use plural names like "Mouths" so you remember it holds multiple drawings inside!
4 Add Sub-Drawings Vector Layers

Drag Vector Drawings Inside the Switch Folder

Create vector layers for each mouth shape (e.g., Smile, O-Mouth, Talk, Surprise). Drag and drop these drawings directly INSIDE your new Switch Folder.

Check alignment: Make sure all drawings are aligned to the middle of your character's face!
5 Swap & Animate Timeline Animation

Right-Click or Select Shapes to Swap Instantly!

When you are on your animation timeline, simply Right-Click on the Switch Folder (or click a mouth in the layer list). Moho will instantly switch the character's mouth on screen!
